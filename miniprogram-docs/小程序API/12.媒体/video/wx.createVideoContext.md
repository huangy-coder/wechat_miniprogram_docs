## 功能描述

创建 [video](https://developers.weixin.qq.com/miniprogram/dev/component/video.html) 上下文 [VideoContext](VideoContext.md) 对象。建议使用 [wx.createSelectorQuery](../../19.WXML/wx.createSelectorQuery.md) 获取 context 对象。

## 参数

### string id

[video](https://developers.weixin.qq.com/miniprogram/dev/component/video.html) 组件的 id

### Object this

在自定义组件下，当前组件实例的this，以操作组件内 [video](https://developers.weixin.qq.com/miniprogram/dev/component/video.html) 组件
