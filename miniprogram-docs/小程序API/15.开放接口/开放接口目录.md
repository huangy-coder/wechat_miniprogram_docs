# 开放接口 API 目录

> 官方入口：[开放接口](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/login/wx.pluginLogin.html)
> 整理日期：2026-05-29
> 所属范围：微信小程序「开发 / API」栏目。

## 功能范围

登录、账号、用户信息、授权、手机号、开放数据、订阅消息、客服、二维码链接、视频号和广告等开放能力。

## 本地条目

- 本分类共整理 57 个独立 API 页面。
- 下方目录保持官方左侧导航层级，并链接到本地 API 文档。
