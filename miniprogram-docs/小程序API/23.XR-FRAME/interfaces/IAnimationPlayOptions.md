## Properties

### delay

• `Optional` **delay**: `number`

播放延迟，默认为`0`。


### direction

• `Optional` **direction**: `"forwards"` | `"backwards"` | `"both"`

播放方向，默认为`forwards`。


### loop

• `Optional` **loop**: `number`

循环次数，默认为`0`。


### speed

• `Optional` **speed**: `number`

播放速度，默认为`1`。
